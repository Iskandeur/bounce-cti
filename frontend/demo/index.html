Bounce-CTI demo: serve this folder over HTTP

Browsers do not run this page's scripts when it is opened from disk (a file:// address), so nothing else would show.

From frontend/: npm run preview:demo, then open the address it prints (http://127.0.0.1:4173/ by default). Or, from this folder: python3 -m http.server 8000 --bind 127.0.0.1, then http://127.0.0.1:8000/. No network and no API key are needed.
