# Contributor License Agreement (retired)

**Bounce-CTI no longer asks contributors to sign a CLA.** Since November 2026,
contributions enter the project under the Apache License 2.0, like the rest of
the code (section 5 of [the license](./LICENSE)). Nothing needs to be signed
before a pull request is merged.

This file stays as the record of the contributions accepted while a CLA was in
place. Contributors who signed it keep the terms they signed for those
contributions: their work was licensed under Apache-2.0 and no more, and the
Maintainer holds no right to relicense it.

## Contributions accepted before the move to Apache-2.0

Before the Project moved to Apache-2.0, the `git log` shows a single external
contributor: one commit (`0ced102`, "fix(stix): make STIX 2.1 export
spec-conformant", pull request #56), accepted under the previous version of this
Agreement. Every other commit was authored by the Maintainer or made on the
Maintainer's behalf. That earlier version let the Maintainer relicense the
contribution under any terms, and the Project is now relicensed under Apache-2.0
on that basis. The patent license for that contribution is the one granted in
section 3 of that earlier version, to the Maintainer and to recipients of the
software the Maintainer distributes, on terms comparable to section 3 of
Apache-2.0. From the Apache-2.0 version of the Agreement on, the Maintainer
holds no such right over any Contribution.

The full text of the retired Agreement is in the git history of this file.
